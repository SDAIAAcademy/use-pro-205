# المختبرات

ثمانية مختبرات لمقرر أكاديمية سدايا **USE-PRO-205**، مدة كل منها 30 دقيقة، واحد في كل جلسة، ومعها ورقة خط الأساس من العمل التحضيري وبطاقة إعادة التصميم للمشروع الختامي. المختبرات صفحات إرشادية بالعربية: الهدف، والملفات، وخطوات بدقائقها وأوامر تُنسخ، وأسئلة تحقق، ومهمة إضافية ✱، وملاحظات للمدرّب. لا يكتب المشارك أي رموز برمجية.

كل المختبرات على حملة واحدة في جهة واحدة: الإطلاق الوطني لخدمة «مُؤنِس» في **هيئة عَضُد الوطنية للعمل التطوعي**، وهي جهة افتراضية. كل الأسماء والأرقام والاقتباسات والصور مختلقة.

## ما يحتاجه المشارك

- متصفح، ومساعد كتابة: المساعد المعتمد في جهته، أو المساعد المتاح في القاعة، أو مساعد عام بخطته المجانية. لا يُنزَّل أي نموذج على الجهاز.
- برنامج جداول لفتح ملفات `csv`، أو الأوراق مطبوعة.
- من لا يتاح له مساعد يعمل على المخرجات المعدّة: لكل خطوة فيها مساعد ملف جاهز بصيغة ما يكتبه مساعد.
- لا يكتب المشارك في أي مساعد شيئًا غير منشور أو مصنّفًا من جهته. كل ما يحتاجه في `files/`.

## تشغيل الحلول

```bash
node labs/solutions/check.mjs            # كل المختبرات
node labs/solutions/check.mjs 2.3 2.4    # بعضها
```

ملف واحد يحتاج إلى [Node.js](https://nodejs.org/) ولا شيء غيره. يطبع لكل مختبر ما أعاد حسابه ثم `PASS`، ولا يكتب شيئًا على القرص ولا يتصل بأي نموذج.

**ما يُشغَّل فعلًا:** المختبران 2.3 و2.4 كاملين: كل ادعاء معاد حسابه من جداول التقرير وسجل الاقتباسات، وقرار كل صورة مشتق من بطاقة أدلتها وسجل الموافقات والتراخيص. ومن المختبرات الأخرى كل ما لا يحتاج إلى نموذج: كشف الأخطاء النصية الخمسة بمطابقة الأرقام والاقتباسات على مصادرها، وقاعدة كل خطأ من الثمانية، وشرطا بطاقة مسار العمل، ومواضع المسودة الأولى الخمسة وأرقام السجل، وحقائق ورقة الحقائق الاثنتان والعشرون في النسخة الإنجليزية المرجعية، والفروق الستة بين النسختين.

**ما يُشغَّل بنموذج بديل:** كل خطوة يؤديها المشارك في مساعد كتابة: المهمة الإضافية في 1.1، والخطوة 3 في 1.3، والخطوة 4 في 1.4، والخطوة 3 في 2.1، والخطوة 3 في 2.2. المخرجات المعدّة في `files/start/` والردود في `solutions/standin.json` مكتوبة باليد، وفيها الأخطاء التي يقع فيها مساعد حقيقي، ليُظهر الفحص أن خطوة التحقق في كل مختبر تلتقطها. لم يُشغَّل أي أمر من أوامر المختبرات على نموذج حقيقي عند إعداد المقرر: يجربها المدرّب على مساعد القاعة قبل كل دفعة، ويعرف أين يخطئ ذلك المساعد اليوم.

**الصور:** الصور الثماني وصورتا الحزمة رسوم تمثّل صورًا، وبطاقات أدلتها مكتوبة باليد: قراءة فاحص بيانات اعتماد المحتوى، ونتيجة البحث العكسي، ومذكرة المورّد. لم تُجرَّب الأدوات الحقيقية على صور حقيقية عند إعداد المقرر. قبل الدفعة يجرّب المدرّب أداة فحص وبحثًا عكسيًا على صورة يملكها، ويعرضهما في الجلسة.

## الملفات

تولَّد الملفات النصية من `labs/_tools/prepare_files.mjs` دون أي عشوائية، وحقائق الحالة كلها في `labs/_tools/world.mjs`:

```bash
node labs/_tools/prepare_files.mjs
node labs/_tools/render.mjs
```

الأمر الثاني يرسم الصور ويحتاج إلى متصفح Chrome على الجهاز، أو إلى مساره في المتغير `CHROME`. الصور مودعة في المستودع، فلا حاجة إليه إلا إذا تغيّر رسم.

| الملف | ما فيه |
|---|---|
| `prework_baseline.html` | ورقة خط الأساس: المهمة، ودقائقها، وأخطاؤها، وتصحيحاتها بعد الاعتماد |
| `brief_launch.html` | موجز إطلاق «مُؤنِس»، وفيه ملاحظات داخلية |
| `style_guide.html` | دليل الأسلوب: الصوت، والعبارات الممنوعة باللغتين، ونص الوسوم |
| `rule_card.html` | بطاقة القواعد الثماني |
| `pilot_report.html` | تقرير المرحلة التجريبية: ثلاثة جداول، والاستطلاع، ومسح الاستعداد للتطوع |
| `approved_quotes.html` | سجل الاقتباسات المعتمدة: اقتباسان باللغتين |
| `glossary.csv` | المسرد ثنائي اللغة |
| `content_pack.html`، `pack_m1.png`، `pack_m2.png` | حزمة المحتوى وفيها ثمانية أخطاء مزروعة |
| `asset_register.html` | سجل أصول الحزمة |
| `fault_log.csv` | سجل الأخطاء فارغًا |
| `workflow_card.html` | بطاقة مسار العمل فارغة |
| `content_log.csv` | سجل المحتوى فارغًا |
| `release_ar_final.html`، `posts_ar.html` | البيان العربي المعتمد والمنشورات الثلاثة |
| `fact_sheet.csv` | ورقة الحقائق: 22 حقيقة بأسمائها، وقيمها فارغة |
| `parity_check.csv` | ورقة فحص التطابق فارغة |
| `claims_pack.html` | عشرة ادعاءات لأسبوع الإطلاق |
| `news_item.html` | خبر صحيفة: مصدر ثانوي |
| `factcheck_log.csv` | سجل التحقق والوسم: عشرة صفوف للادعاءات وثمانية للصور |
| `image_cards.html`، `images/` | الصور الثماني وبطاقات أدلتها |
| `consent_register.html` | سجل الموافقات والتراخيص |
| `label_consent_guide.html` | دليل الوسم والموافقة |
| `redesign_card.html` | بطاقة إعادة التصميم |
| `start/` | نقاط البداية الجاهزة: سجل الأخطاء بعد النصوص، وجلسة الصياغة وسجلها، والمسودة الأولى، والمسودات الإنجليزية، وسجل التحقق بعد الادعاءات |

## بعد تغيير أي ملف

غيّر الحقيقة في `world.mjs`، وأعد توليد الملفات، ثم شغّل `check.mjs`. الأرقام التي تقتبسها الشرائح وصفحات المختبرات يطبعها الفحص نفسه: إن تغيّر رقم في جدول فحدّث الشرائح والصفحات على ما يطبعه.
